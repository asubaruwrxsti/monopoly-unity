# Monopoly (Unity)

A complete game of Monopoly (London edition) for Unity 6, playable on one device (hot-seat, with
computer players) or online with friends.

## Getting started

1. Open the project in **Unity 6000.2.7f2**.
2. Open `Assets/Scenes/Monopoly.unity` and press Play.
   (If the scene is missing, run **Monopoly > Rebuild Game Scene** from the menu bar.)

## Playing

- **Play on this device**: add players who share this screen, plus any number of computer players (2-6 in total).
- **Host an online game**: creates a lobby and shows a join code. You can add computer players and extra
  local players too.
- **Join an online game**: enter the host's join code.
- **LAN mode** (on the host/join screen): connect by IP address on the same network, no account needed.
  The host's lobby shows the address to use (port 7777).

Click any space on the board to see its title deed. Use **Properties** on your turn to build houses
and hotels, sell buildings, or mortgage and unmortgage.

### Tokens

Every player picks a token in the lobby, using the arrows next to their name. The pieces are:

- **Classic metal pieces**: Boot, Top Hat, Race Car, Battleship, Iron, Thimble, Wheelbarrow and Rubber Duck.
  They're generated procedurally (`TokenModels`), and each has its own way of moving and reacting. The boot
  stomps, the race car drives and does donuts, the top hat flips, the ship rocks, and so on.
- **Animated heroes**: Knight and Valkyrie, from the RPG Tiny Hero Duo pack. They run between spaces and play
  victory, level-up, dizzy, hit and defeat animations.

To add a token, add an entry to `TokenCatalog` and a builder in `TokenModels`.

### Presentation

- `BoardCamera` is a cinematic camera director. It slowly orbits the board in menus, frames the token
  showcase in the lobby, and chases the moving token during play. It swings around the board so each
  side's tiles read the right way up, and adds shake on dice impacts.
- 3D dice are thrown and always land on the rolled values.
- Effects include confetti, coin streams and rain, tile glows, owner plaques that drop in, and houses that
  pop up.
- Post-processing (bloom, colour grading, vignette, ambient occlusion, and depth of field that tracks the
  camera's focus) comes from the Post Processing package. The profile is
  `Assets/Monopoly/Settings/PostFxProfile.asset`.
- Sound effects are synthesised in code (`Sfx`), so no audio files are needed. Swap in recorded clips there if
  you have them.
- The UI uses the classic Monopoly typeface, ITC Kabel (copied from `Assets/TextMesh Pro/Fonts` into
  `Assets/Resources/Fonts`). ITC Kabel is a commercial font, so check its licence before you ship.

### Online play setup (join codes)

Join codes use Unity Relay, which needs the project linked to Unity Cloud once:
**Edit > Project Settings > Services**, then pick or create a project. Relay's free tier is enough.
LAN mode works without this.

### Rules implemented

Full classic rules: buying, rent (doubled on complete colour sets), stations and utilities, houses and hotels
with even building and a 32-house/12-hotel bank supply, mortgages (10% interest to lift), all 32 Chance /
Community Chest cards, Get Out of Jail Free cards, jail (fine, card, or doubles; forced fine on the third try),
three doubles sends you to jail, income/luxury tax, raising money when you can't pay, and bankruptcy (assets go
to the creditor).

Not implemented: auctions (a declined property stays with the bank), trading between players.

## Project layout

```
Assets/Monopoly/

  Game/      Unity layer: GameBootstrap (entry point), GameFlow (event playback), BoardView, TokenView,
             BoardCamera (camera director), LobbyShowcase, NetSession (networking), UI/HudController,
             Tokens/ (catalog, procedural models, portraits), Fx/ (dice, effects, scenery, post FX, sound)
  Editor/    MonopolySetup (scene builder, menu items), tile texture import settings
  Tests/     EditMode tests for the rules engine
Assets/Resources/
  Tiles/     Board tile artwork, loaded by name from BoardLayout
  UI/        GameHud.uxml (layout), GameHud.uss (styles), MonopolyTheme.tss
  Monopoly/  Generated by Monopoly > Rebuild Game Scene: materials, sky, hero animator and HeroAssets
  Fonts/     ITC Kabel for the UI and the board logo
```

### How it fits together

- **Rules engine** (`MonopolyGame`): every player decision is a `GameCommand` (Roll, Buy, BuildHouse...).
  The engine validates it, updates state instantly, and queues `GameEvent`s (dice rolled, token moved, card drawn,
  log line).
- **Presentation** (`GameFlow`): replays those events as animations, then refreshes the HUD. CPU players pick
  one command at a time via `CpuPlayer.ChooseCommand`.
- **UI** is UI Toolkit. The layout and styles are plain text files you can edit in **UI Builder**
  (`Window > UI Toolkit > UI Builder`, open `GameHud.uxml`). `HudController` only fills in data and
  forwards clicks, so there are no inspector references to break.
- **Multiplayer** (`NetSession`) is host-authoritative lockstep over Netcode for GameObjects. Every peer runs
  the same deterministic engine from a shared seed. Clients send command requests, and the host validates
  them and broadcasts accepted commands in order. Peers compare a state hash after each command to detect
  desyncs. If a player disconnects mid-game, a computer player takes over their seat.

### Tests

Run them from **Window > General > Test Runner > EditMode**, or from the command line:

```bash
Unity -batchmode -projectPath . -runTests -testPlatform EditMode -assemblyNames Monopoly.Tests
```

They cover rent, building rules, jail, cards, debt and bankruptcy, and replay determinism, and they simulate
complete 4-player CPU games.

### Command-line builds

```bash
Unity -batchmode -quit -projectPath . -executeMethod Monopoly.Editor.MonopolySetup.BuildMac -buildPath Builds/Monopoly.app
```

`DevAutoplay` is a smoke-test driver that only activates when the player is launched with
`-monopolyAutoplay <local|tokens|host|join> <screenshotDir>`.

### GitHub Pages CI

`.github/workflows/github-pages.yml` builds a WebGL player with
[game-ci/unity-builder](https://game.ci/) on every push to `main` and publishes it to GitHub Pages. It needs a
Unity license available as repository secrets: either `UNITY_LICENSE` (a Unity Personal/Pro `.ulf` license file)
or `UNITY_EMAIL` + `UNITY_PASSWORD` (and `UNITY_SERIAL` for Pro). GitHub Pages must also be enabled for the
repository with the source set to **GitHub Actions** (Settings > Pages).
